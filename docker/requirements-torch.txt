# Self-contained, fully pinned dependency set for the torch grader image.
#
# This image is NOT built on top of requirements-full.txt: it carries its own copy of the scientific
# stack so its build is reproducible and can pin versions independently of the full image. PyTorch is
# tightly coupled to specific numpy/Pillow versions, and this image runs on a different Python and
# libc (glibc / 3.13) than the full image (musl / 3.14), so it needs to pin those on its own terms.
#
# Trade-off: when a package is added to the full image it must be mirrored here by hand; that drift is
# intentional, so that changes to this heavy ML image are always explicit and reviewed.
#
# torch and torchvision are served from the PyTorch CPU index (https://download.pytorch.org/whl/cpu),
# which Dockerfile.torch sets as the primary index so only CPU wheels are pulled (no CUDA). Every
# other package falls through to PyPI. torchinfo (the maintained successor to torchsummary, for
# model/parameter summaries) comes from PyPI.
